# fixSoThat

React front page with a single animated feature component that says "Hellow world".

## Use pnpm (modern)

1. Install dependencies:

	```powershell
	corepack pnpm install
	```

2. Start dev server:

	```powershell
	corepack pnpm dev
	```

3. Build for production:

	```powershell
	corepack pnpm build
	```
