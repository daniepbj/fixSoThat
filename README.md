# fixSoThat

React front page with a single animated feature component that says "Hellow world".

## Use pnpm (modern)

1. Install dependencies:

   ```powershell
   corepack pnpm install
   ```

2. Start dev server:

   ```powershell
   corepack pnpm dev
   ```

3. Build for production:

   ```powershell
   corepack pnpm build
   ```

## Deploy to GitHub Pages

1. Install dependencies (includes deploy tooling):

   ```powershell
   corepack pnpm install
   ```

2. Publish the built `dist` folder to `gh-pages` branch:

   ```powershell
   corepack pnpm deploy
   ```

3. In GitHub repo settings, set Pages source to `gh-pages` branch.
